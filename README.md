# CadenceRead

> Reading pace, syllable & clarity analyzer for crisp technical writing.

**Tier:** Tier 1: Foundational | **Stack:** HTML / CSS / JS

## Overview
Build CadenceRead: a responsive, accessible writing analyzer that counts words, estimates reading time, measures sentence cadence & syllables, and verifies its core logic with console.assert() checks.

## Milestones
- [x] **Milestone 1: Word Counter, Read Time & Assertions** — Implement countWords(text) and formatReadTime(words, wpm), wire live input events, and pass your first console.assert() checks.
- [ ] **Milestone 2: Sentence Cadence & Syllable Heuristic** — Add sentence counting, syllable estimation, and a live pace badge (Crisp / Balanced / Dense).
- [ ] **Milestone 3: Sample Presets, Clear Action & Touch Polish** — Add Load Sample and Clear buttons with 44px touch targets, focus outlines, and zero A11y warnings.
